# Building Electrical Distribution System

A complete electrical distribution system design study for a hypothetical 3-storey commercial office building in Ottawa, ON. This project demonstrates a full engineering design workflow following the Ontario Electrical Code (OEC) and NEC 2023 standards.

## Project Scope

- **Building:** 3-storey commercial office, 120/208V 3-phase 4-wire
- **Total design load:** 43.0 kW across lighting, power, mechanical, and safety systems
- **Main distribution board:** 400A with 54% spare capacity for future expansion

## Deliverables

| File | Description |
|------|-------------|
| `building-power-calcs.xlsx` | Load schedule, voltage drop analysis, cable sizing, cable run sheet |
| `single-line-diagram.svg` | Full distribution system single-line diagram |
| `technical-report.pdf` | 7-section technical report with calculations and conclusions |

## Tools & Standards
- Microsoft Excel — load calculations and cable sizing
- SVG / AutoCAD — single-line diagram
- Ontario Electrical Code (OEC) CSA C22.1
- NEC 2023 Table 310.15(B)(16) for conductor ampacity

## Key Results
- All branch circuits pass 3% voltage drop limit (OEC requirement)
- Short-circuit current at MDB: 13.9 kA — within all breaker ratings
- Emergency and safety circuits on dedicated breakers per code
